# Homework 2 Report

## Abstract

Контроль — SasRec-I2I: якорь из истории выбирается случайно с весом listen time, следующий трек берётся из предвычисленного I2I. Тритмент — Session Graph-MF: по графу SASRec-I2I + LightFM-I2I считаются SVD-эмбеддинги треков, вектор сессии собирается онлайн как recency/time fold-in, кандидаты берутся из HSTU и I2I, а скор `u·i` штрафует повтор артиста. Это нужно, потому что в симуляторе повтор артиста режет долю дослушивания. Модель ML, а не эвристическая правка одного SasRec.

## Детали

Офлайн: взвешенный item-item граф (вес 1/rank) раскладывается TruncatedSVD (64d). Онлайн: история из Redis (до 10 событий); кандидаты = HSTU пользователя ∪ I2I последних треков с time ≥ 0.35; скор = cosine(user, item) + бонус I2I/HSTU − 0.40 за артиста из последних 4 треков. A/B: `SESSION_GRAPH_MF`, 50/50, C = SasRec-I2I, T1 = Session Graph-MF. Сид 31312, 30 000 эпизодов.

```
SASRec/LightFM I2I ──► граф ──► SVD item emb     HSTU user list
                                      │                │
история ──► fold-in user vec ──► score + artist penalty ──► next
```
